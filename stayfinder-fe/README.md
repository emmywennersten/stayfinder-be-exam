# StayFinder – frontend

Next.js-frontend för StayFinder. Pratar med backend (`stayfinder-be`) via fetch med cookies.

## Kom igång

1. Kopiera `.env.example` till `.env.local`:
   ```
   NEXT_PUBLIC_BACKEND_URL=http://localhost:3000
   ```
2. Installera och starta:
   ```
   npm install
   npm run dev
   ```
3. Öppna http://localhost:3001 (backend ska köra på port 3000).
